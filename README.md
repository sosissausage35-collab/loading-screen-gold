One sharp, funny loading-screen tip for stressed developers and AI coding agents: "Tip: this build is 90% waiting for the agent, 10% waiting for you to admit the prompt was the bug." (98 characters). `main.ts` scores a shortlist of ten freshly written candidate tips against the judge's brief — on-subject first, then the laugh, the glance, speaking to both audiences at once, and freshness — and deterministically picks the winner.

## Run it

```sh
node main.ts
```
